## 两个必须知道的前提

1. **材料未填写完毕**：`学海星槎-项目计划书.docx` 与 `01-报名信息与项目概述.md` 里的
   项目负责人、团队名称、所在学校、指导教师仍是 `【姓名】`「【学校名称】」这类占位符；
   计划书里还有一处 `【待补充：请填写定价与测算依据】`。若将来要用，先把这些补齐。
2. **项目名称不一致**：这批材料对外用 **学海星槎**，而 App、仓库、GitHub Release、
   包名（`com.brainquest.game`）全部是 **脑力大冒险 / BrainQuest**。
   上架前必须二选一并全局统一（建议改显示名而不是包名，包名一改签名链与老用户更新全断）。
