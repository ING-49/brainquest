## 一、统筹页

### 1. 全局约束（不可破的纪律）

- **语义色纪律**：金＝收益/消费（FFB300 系）、红＝危险/错误（敌方血 E53935 与错误提示 C62828 两红分用不混）、绿＝完成/我方生命（2E7D32/43A047）、紫＝新玩法（7C4DFF）。**不得新增第五种语义色**；任何新色必须先归入既有语义，归不进去＝方案无效。
- **两个视觉世界**：浅色 M3「文档世界」（大厅/答题战斗/支撑页/小游戏页）与深色金属「场景世界」（地牢/幸存者）。**不得把文档世界改成场景世界**（往 M3 页搬暗金属面板、0x72 精灵＝违例），反之亦然；跨界只允许走既有共享通道：语义色、CoinIcon、BqProgressBar、pressScale。
- **圆角像素语言**：文档世界全圆角无尖角（12–16dp 圆角＋软影）；场景世界像素实体必须 `FilterQuality.None`（坑40）；**emoji 不承担唯一关键视觉**（坑20 🪙 豆腐块前科）——新设计若让 emoji 独扛形象语义，方案无效。
- **布局合法性先行**：任何改动先更新对应设计卡、声明 P0/P1/P2 层级与动线位置；「好看」不是验收语言。

### 2. 优先级

| 级 | 对象 | 一句理由 |
|---|---|---|
| **P0** | 速算英雄·答题战斗屏 | 故事最弱却最核心——核心玩法、最高频画面，四部件中「故事」最弱（出招无身体、敌人无群像、我方无身份），断层直接压在主循环上 |
| **P1** | 关键位 emoji 自绘化 | 有前科的风险——敌人形象/身份/结算星全靠 emoji 与 ZWJ 组合字符独扛，跨设备渲染不可控，坑20 有实录 |
| **P2** | 大厅轻场景化 | 不影响主流程——大厅按自身范式已审计达标（批25/29/31/32/57），框架照出的「无场所感」与其「30秒决策」使命存在张力，收益有限、风险有限 |
| **不动** | 地牢/迷你幸存者/三小游戏/结算演出/闯关地图 | 各自在品类宣言下已达标（地牢＝五法则满分答卷、结算＝峰终标尺、三小游戏材质即故事），改动需先在不动清单除名 |

### 3. 参照系（标尺与对照方法）

- **场景世界标尺＝地牢**：火把光锥（中心亮四周暗）、门徽预告系统、墙线三段内阴影。对照法：任何场景提案先回答「它在地牢标尺下哪个部件最弱」。
- **文档世界标尺＝大厅**：语义色纪律、呼吸金边＝全页唯一动面、12dp 等距节奏。对照法：任何界面提案先回答「它在大厅标尺下哪个部件最弱」。
- **动效标尺＝批57 结算演出**：星星 spring 递增 130ms、金币滚动 680ms 后 600ms、满星金色脉动。任何新反馈时刻的动效投资不得低于此水准，否则宁可不加。
- **实测对照法**：截图缩至 50% 比剪影可读性；录屏 3 秒遮住文字看动作时序是否可读。

### 4. 委派原则

- 执行方每卡先交**证据包**：实机截图三落点标注（第一眼/然后/最后，须自采证据，**不得引用本文档结论充当证据**）＋一句话诊断＋**≥3 个方案**＋推荐与放弃理由。
- **只交一个方案＝退回**；方案未声明落在五法则哪一条＝退回；方案违反全局约束任一条＝退回。
- 顺序锁死：P0 卡未验收不动 P1，P1 未验收不动 P2，不动清单无令不动。
