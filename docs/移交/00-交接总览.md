## ⚠️ 三条红线（动手前务必知道）

1. **签名密钥不在 git 里。** `keystore/brainquest-release.keystore` 与 `keystore/keystore.properties`
   被 `.gitignore` 排除，只存在于这台机器的磁盘上，**没有备份**。
   丢了 = 老用户无法原地更新（签名不一致，系统必须卸载重装），上架后也无法再更新。
   → 立刻按 [`01-资产与凭据.md`](01-资产与凭据.md) 做离线备份。
2. **公网服务器上有真实玩家数据。** `/opt/pk/ratings.json`（ELO 积分）与 `/opt/pk/saves/`（云存档）
   是真人产生的，删了不可恢复。任何重装/迁移/清库操作前先备份。
3. **`update-server/apks/` 里的历史 APK 是补丁链的原料，勿删。** 少了任何一个版本，
   那个老版本的用户就只能走全量下载（多耗 ~4MB 流量），新生成的补丁链也会断。

## 恢复开发：最短路径（5 步）

```bash
# 1) 拿代码
git clone https://github.com/ING-49/brainquest.git && cd brainquest

# 2) 环境（Windows 上这些已 setx 到用户级；换机器需重设）
export JAVA_HOME=E:/Tools/jdk-17.0.20.1+1          # ⚠️ 别用 Android Studio 自带 JBR（Java 25 会让 Kotlin 2.0 崩）
export ANDROID_HOME=E:/Tools/Android-Studio/Android/SDK
export ANDROID_AVD_HOME=E:/Tools/Android-Studio/avd-home   # 不设会报 Unknown AVD name

# 3) 从备份恢复签名（没有它只能出 debug 签名的包，发不了版）
cp -r <你的备份>/keystore ./keystore

# 4) 编译
./gradlew clean assembleDebug

# 5) 确认环境与代码都正常（纯逻辑校验，不需要模拟器）
python tools/klotski_verify.py     # 华容道 6 关 BFS 可解性 + 最少步数
```

想跑模拟器验证就先启动 AVD `BrainQuest`，再 `adb install -r app/build/outputs/apk/debug/app-debug.apk`。
完整环境、发版、部署步骤见 [`02-恢复开发.md`](02-恢复开发.md)。
