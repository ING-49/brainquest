### 备份玩家数据（建议每季度或迁移前做一次）
```bash
# 在服务器上打包
ssh root@8.148.192.129 'tar czf /root/pk-data-$(date +%F).tgz -C /opt pk'
# 拉回本地
scp root@8.148.192.129:/root/pk-data-*.tgz ./backup/
```
迁移到新机器：装 python3 + `websockets` → 上传 `pk_server.py` → 把备份的 `pk/` 解回 `/opt/pk`
→ 建 systemd 服务（照抄 `tools/deploy_pk_server.py` 里生成的 unit）→ `systemctl enable --now pk-server`
→ 在新地址上跑一次 smoke 自检 → 最后才改 App 里的服务器地址（`data/PlayerState.kt` 的默认值与
`game/pk/PkBattleScreen.kt` 里的 `DEFAULT_PK_SERVER` 兜底值）。服务器本身无状态，
真正要带走的就是 `ratings.json` 与 `saves/`。
