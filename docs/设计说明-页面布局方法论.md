# 页面设计方法论 —— 每页为什么这样排

> 本文档回答"这页为什么长这样"。任何 UI 改动**先对表再动手**：改布局前先更新对应设计卡，说明依据哪条原则。
> 表层好看（配色/间距/动效）由批31/32 的组件层承担；本文档管的是**布局合法性**——信息放哪、为什么放哪。

## 一、方法论框架：五问

设计或改动任何页面，先回答：

1. **使命**：用户来这页做什么？（一句话，说不出使命的页面就是堆料）
2. **信息优先级**：P0 = 不看就亏 / P1 = 需要时能找到 / P2 = 支持性内容
3. **视觉动线**：第一落点 → 第二 → …（最大最亮的元素必须是 P0）
4. **行动层级**：唯一主 CTA → 次级入口 → 弱化入口（等权按钮 = 没有按钮）
5. **留人钩子**：这页埋了什么"回来/继续"的机制

## 二、心理机制词汇表（留人钩子用这套说话）

| 机制 | 在本项目里的落点 |
|---|---|
| 齐加尼克未完成感 | 「继续冒险·第N关」CTA、关卡列表「▶ 进行中」徽章 |
| 目标梯度效应 | 科目卡 x/8 进度条、关卡列表头部进度、XP 条（越接近完成越有动力） |
| 每日循环 | 签到 + 每日挑战并排卡置顶、每日任务卡片 |
| 损失厌恶 | 🔥 连续挑战 N 天（streak 可见即怕断） |
| 进度可见性 | XP 条、图鉴 x/12、成就 x/y |
| 新鲜感 | 「新玩法」角标（地牢） |
| 强反馈时刻 | 领金币按钮金亮 + "+N" 浮字、答题对错即时变色 |
| 心流（难度匹配） | 关卡难度梯度文案「难度 N」、BOSS 关明示 |

## 三、每页设计卡

### 1. 主页大厅
- **使命**：30 秒内决定"今天玩什么"，顺手带走每日收益
- **P0**：每日签到/挑战（收益入口）｜游戏中心双主角卡
- **P1**：每日任务、联机对战
- **P2**：功能三芯片（错题/商店/成就）、道具、最佳成绩
- **动线**：用户卡（身份锚点+Lv/XP）→ 日常行（收益）→ 任务明细 → 游戏中心（内容选择）→ 联机横条 → 支持系统
- **CTA**：每日挑战卡（金亮+呼吸=可领取）> 游戏主角卡 > 其余全部弱化
- **留人**：每日循环三件套置顶 + 🔥streak + 主角卡层级化（核心玩法/新玩法角标）
- **现状**：✓（批25 布局 / 29 层级 / 31 语义色 / 32 动效均已对表）

### 2. 闯关地图
- **使命**：选今天打哪科（老玩家 3 秒内进战斗）
- **P0**：继续冒险 CTA（直达上次进度关）
- **P1**：已解锁科目卡（进度条+开始胶囊）
- **P2**：未解锁科目（锁+「前一科通过 2 关解锁」= 下一目标预告）
- **动线**：CTA 第一落点（全页唯一暖色金色播放钮）→ 科目网格自上而下即解锁顺序
- **留人**：未完成感（继续）+ 目标梯度（进度条）+ 解锁预告
- **现状**：✓（批30/31）

### 3. 关卡列表
- **使命**：明确"打哪一关"
- **P0**：下一关（主色描边 + ▶ 进行中徽章）
- **P1**：已通关关卡（星星数）、BOSS 关
- **P2**：未解锁（灰化）
- **动线**：头部进度条 → 当前关（列表第一屏）→ 往下扫
- **留人**：目标梯度 x/8 + 当前位置标记（永远知道下一步）
- **现状**：✓（批31）

### 4. 答题战斗
- **使命**：答题→攻击的实时决策
- **P0**：题面+选项 ｜ 双方血条（局面信息）｜ 出招反馈层（批60，瞬时层不占布局）
- **P1**：限时提示、伤害飘字（即时反馈）
- **P2**：提示/跳过（兜底道具，弱化不抢注意力）
- **动线**：敌人（目标）→ 我方（状态）→ 题卡（行动）→ 工具（兜底）
- **留人**：即时反馈（飘字/音效/选项变色）
- **出招反馈层（批60）**："答对出招 答错挨打"从纯文字变成双向动作时序：答对=我方头像蓄力→primary 色光痕飞向敌人→命中环+敌人抖动闪白；答错=敌人前扑→E53935 光痕下击→我方状态卡红闪。预备→飞行→命中→回弹四段，投资对标批57 结算演出标尺；实现为根级一次性 Animatable 叠层，不引入画布/帧循环，不改任何信息层级
- **怪种身份色（批60）**：名字/形象/光环**三位一体七系**（修实证错位：原 emoji 按 level%4、名字按 (level-1)%7 轮换，Lv1「哥布林」显示 🧟）——哥布林👺赤 E53935｜史莱姆🦠橙焰 FF7043｜小恶魔😈绛 C2185B｜蝙蝠兵🦇紫 7E57C2｜石头人🗿石板 78909C｜暗影法师🧙深靛 5C6BC0（地牢 caster 同源）｜骷髅武士💀骨白 B0BEC5（地牢 skeleton 同源）；BOSS 恒红 👹 88dp 放大+描边环（§18 BOSS=红渐变语言）。光环=**实体身份色，不承担 UI 语义**，危险语义仍由幕布+E53935 血条独扛；绿/PK蓝(42A5F5)/金(FFB300) 不用于怪种（避让 完成/PK我方/奖励 三语义）；新引 emoji 的老设备缺字风险归卡2 审计
- **我方身份（批60）**：状态卡接入 AvatarBadge(32dp)（与大厅同组件），替换写死的 🧑‍⚔️——我方"有身体"后才有资格成为出招主体
- **敌人自绘＋结算星自绘（批61，卡2）**：八系怪（七系+BOSS）由 `game/quizbattle/EnemyArt.kt` DrawScope 绘制（剪影互异+批54 明暗三件套），`Text(emoji)` 实体形象位清零（坑20：emoji 不承担唯一关键视觉）；结算 ★☆ 与 ⭐ 经验换 `Common.StarIcon` Canvas（CoinIcon 同款模式）——Roboto 字形跨密度不一致消除
- **违例 ✗（批33修）**：我方状态条右侧显示金币——金币与战斗决策无关，属于页面噪声，撤出
- **现状**：✓（批41 暗带 / 批57 卡化柔化 / 批60 出招反馈层+怪种身份色+我方身份 / 批61 敌人自绘+结算星自绘）

### 5. 每日挑战（启动页）
- **使命**：讲清规则，促成「开始」
- **P0**：开始按钮（**主 CTA 必须有按钮形态**，不能藏进信息卡）
- **P1**：模式说明、奖励预告（动机钩子）、streak
- **P2**：难度切换指引
- **违例 ✗（批33修）**：整卡可点但视觉是信息卡（用户不确定点哪）；无奖励预告；streak 弱化埋在副标题
- **现状**：✓（批33 CTA 形态 / 批63 结算星 Canvas 化（复用卡2 StarIcon）＋CTA 深棕对齐 4E342E＋真题入口 pressScale）

### 6. 战斗结算
- **使命**：宣告结果 + 发放收益 + 引导再来
- **P0**：星级结果；P1：奖励；P2：返回
- **现状**：✓（批38 审计修正——胜=「下一关」直达下一关卡 / 败=「重新挑战」或复活药水，重开路径已最短，无需再加按钮）

### 7. 我的
- **使命**：查看积累，进入支持系统
- **P0**：身份卡（头像/Lv/金币）；P1：四统计（语义色）、本周学习、成就/错题/商店入口；P2：设置
- **动线**：身份 → 数字 → 周回顾 → 入口列表
- **留人**：本周学习即空状态也有引导文案（"去闯一闯吧"）
- **现状**：✓（批31/32 / 批63 商店 tint 归一 FFB300（"花钱动作一种颜色"）＋四区块 enterStagger 入场）
- **现状**：✓（批31/32）

### 8. 商店
- **使命**：花金币（游戏内经济的出口）
- **P0**：金币余额（动态计数动画已有）
- **排序**：道具（效用）→ 主题 → 头像（表达）＝ 效用 > 表达 ✓

### 9. 错题本
- **使命**：学习闭环（错 → 复习 → 掌握）——**教育循环与游戏循环并列**，这是产品定位
- **P0**：今日待复习（艾宾浩斯队列）；P1：全部列表+已掌握标记；P2：导出 CSV
- **现状**：✓

### 10. 设置
- **使命**：个性化 + 维护
- **P0**：音效/震动/考研模式（用户可感）；P1：云存档、更新中心；P2：隐私
- **开发者更新地址 = 长按头部唤出**的隐藏手势，不占普通用户信息层级 ✓
- **现状**：✓（批63 通用设置区块卡＋云存档入口 pressScale＋更新中心按钮 pressScale/fillMaxWidth）

### 11. 联机对战
- **使命**：与真人对局（社交竞争）——**品类=竞技，视觉要有对抗能量**

### 13. 横屏游戏内 HUD
- **范式**（批24 确立，GameUi.kt 头注）：左上玩家信息 / 顶部目标信息 / 右上功能 / 右下操作簇（右手拇指区 = 主操作）
- **红线**：HUD 元素画在世界变换之外（坑35）；弹窗叠加顺序（坑40）
- **沉浸全屏**（批37）：地牢屏进入即隐藏系统栏（sticky，下拉临时呼出，离开自动恢复）——横屏可视高寸土寸金，状态栏+insets 曾把顶栏/HUD 整体下压（"最上面的部分不够上"）；装备栏 top 92→62、大厅主体 56→52 贴紧顶栏
- **安全区系统（批61，荣耀 DVC-AN00 真机实证·两层级因）**：①window 层——manifest `windowLayoutInDisplayCutoutMode="always"`＋运行时同步 ALWAYS（EMUI/Magic OS 窗口 letterbox 已被归一化，实证**非**空带主因）；②**Compose 层才是主因**：Magic OS 横屏仍按竖屏方向上报挖孔 Top inset（实测 78px），`safeDrawing.Top` 把顶栏整体压出空带 → **横屏游戏屏 Top 锚定一律 `statusBars`（隐藏后=0，贴合；下拉临时呼出才让位）**，Horizontal/Bottom 仍 safeDrawing（真·侧挖孔照避让）——统一收口 `GameUi.gameTopInsets()`（@Composable Modifier 扩展）；**沉浸权=AppRoot 单一所有者**（地牢/幸存者屏级 hide/show 全部移除——横屏路由间跳转时旧屏 onDispose{show()} 后执行会赢，系统栏复现）；窗口重获焦点即重 hide（Magic OS 恢复前台会吐回状态栏）；摇杆圆心按左/下 insets 夹取
- **元气骑士基准（批61 舒适度）**：贴角但不贴死——统一 12dp 角距（主操作簇拇指区 18dp 保留为有意设计）；GameDialog/幸存者各状态补 safeDrawing（Pixel 视觉零变化）；圆钮统一 42dp（攻击 88/技能 64 层级保留）；地牢大厅顶栏 Column 化，去 magic top=52（顶栏高度变化不再错位）
- **纵深语言**（批34 起）：① 物理纵深=脚下影子（已有）+ Y-sort 遮挡（批36 已做：玩家与敌人按脚底 y 统一排序绘制，谁靠下谁在前）；② 光影纵深=玩家火把光（以玩家为中心的径向暗角，远暗近亮，批34）+ 房间四边内阴影（房间=下沉的坑，批34 补全）+ 玩家微光环（已有）；③ 运动纵深=punch-zoom/震屏/Boss 拉远（已有）。页面级纵深=P0 卡片投影浮起、P2 卡片平贴（批34 主页/地图已应用）；批35 铺满全界面：GamePanel 面板统一柔影（面板=前景浮层）、暗色大厅选中卡浮起（选中=抬高）、GameActionButton 主按钮投影、关卡列表下一关卡 M3 elevation 8dp、每日挑战启动卡 4dp

## 四、改表流程（硬规则）

1. 改任何页面布局前，先更新本文档对应设计卡（写明依据）
2. 新增元素必须声明属于 P0/P1/P2 哪层，插在哪条动线位置
3. 新增页面必须先写设计卡再写代码
4. 与设计卡冲突的改动 = 违例，要么改设计要么改实现，不许含糊

## 十六、图鉴系统（批47-49 确立）

三部曲：**地牢怪图鉴（12 条目）**、**幸存者数学空间图鉴（4 条目）**、**人物图鉴（3 职业）**，共用地牢图鉴页入口（大厅顶栏 📖）+ Tab 分类（🧟怪物/👤人物）。

- **收集层原则**：击杀才解锁（路过不算）；未解锁显示"？？？/档案加密"——收集驱动
- **档案详情原则**：点卡片开详情页（120dp 大立绘精灵帧 + 属性三色相对条 + 攻击特点/行动习惯/出没四段文案 + 累计击杀数）——文案数据源自引擎真实 AI 与刷怪规则，不许编造
- **持久化原则**：seenMonsters/monsterKills/survivorSeen/classRuns 全部在 **exitToLobby 与 confirmExit 时也合并**（批47 修复：此前中途退出丢记录），结算时再合并一次（幂等）

## 十八、旅程链路美术（批57-58 确立：从大厅到游戏内的断层补齐）

主页大厅批29-39 已高度风格化，但探查发现两条美术断层：**学习主链路**（闯关地图→关卡列表→答题战斗→结算）与**支撑页**（错题本/商店/成就）仍是裸 M3。本节补齐，三条原则：

### 1. 峰终定律：结算演出是战斗体验的"终"
战斗记忆由终点时刻决定——结算从默认 AlertDialog 换成自定义 overlay 演出卡：
- 入场 goIn（淡入+微缩放 220ms，批53 GAMEOVER 同款）
- **星星逐个弹出**：spring 弹性 overshoot，延迟递增 130ms——奖励时刻的仪式感
- 奖励 CoinText（代码绘制金币图标，坑20）+ 数字滚动（Animatable 0→N）
- 满星金色脉动；失败卡解析独立成卡 + 复活 CTA
- BackHandler 防返回键穿透到战斗确认弹窗
> 对照：地牢结算（批50 ResultStat）与幸存者 GAMEOVER（批53）同属"终"的投资。

### 2. 色彩语言一致性：同一种意思只用同一种颜色
- **金币消费=金色**：商店购买按钮 FFB300 底深棕字（与主页任务领取按钮同语言）——"花钱"这个动作全站一种颜色
- **错题红绿语义分离**：你的答案=红（error）、正确答案=绿（2E7D32 Bold）——原来整行红，正确答案也红=语义噪声
- **BOSS=红渐变**：关卡列表 BOSS 卡红渐变描边+红渐变圆底图标+标题红化——危险身份色一眼区分
- 进行中=primary 胶囊（科目卡与关卡行同语言）

### 3. 齐加尼克引导：消除"下一步在哪"的不确定性
- 闯关地图"进行中"科目徽章（与继续冒险 CTA 同源计算，无新增存储）
- 关卡列表锁定行改"通关第 N 关解锁"（原"难度 N"不回答"差一步在哪"）
- 已通关科目金色 ✓（完成感）；空错题本"🎉 错题清零"卡（空白列表无反馈）

### 场景衔接（形/质）
- 暗带上下缘 10dp 渐变柔化（保留全宽出血，消除硬切）
- 敌人脚下椭圆地面阴影（悬浮→落地）
- 我方状态卡化（营地卡与敌方幕布视觉对等）
- NavHost 全局过渡：前进=淡入+自下微升 2.5%，返回对称（纯透明度/位移，不触发重排）

> 教训：非点击 Card（无 onClick）没有 interactionSource 参数——pressScale 只能接在真正可点的组件上（Button/Card(onClick)）；压感反馈给无行为的卡是无效代码。

### 4. 支撑页收尾（批63）
设置/云存档/真题/每日挑战/我的——语义色纪律收口：**云存档 上传=金（保存成果）/恢复=绿（完成）/删除与覆盖恢复确认=危险红**、真题答案=绿 Bold（批58 红绿语言对齐）、每日挑战 CTA 深棕对齐 4E342E＋结算星 Canvas 化、设置通用项区块卡化、我的商店 tint 归一 FFB300＋四区块 enterStagger、pressScale 全覆盖。支撑页至此全部过美术批；游戏画面真机 QA（地牢局内 59fps/HUD 贴合、幸存者 READY、华容道列表）实证无回归。
